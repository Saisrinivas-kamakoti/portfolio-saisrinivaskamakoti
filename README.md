### 🏏 A Cricketer's Worth — IPL Auction 2025
**[View Report (PDF)](./A%20Cricketer's%20Worth%20-%20Predicting%20the%20bid%20prices%20of%20players%20in%20the%20IPL%20auction%202025%20(1).pdf)**

**Overview:**  
Built a machine learning model to predict the bid prices of cricketers in the IPL 2025 auction. The project simulates real auction dynamics, helping teams understand fair valuation and bidding strategies based on player performance metrics.

**Key Highlights:**
- 🎯 Framed as a regression problem with player statistics as features
- 🤖 Applied and compared multiple ML models (e.g., Random Forest, Gradient Boosting, Linear Regression)
- 💡 Identified top predictors of player value — batting average, strike rate, wickets taken
- 📊 Visualised auction price distributions across player categories

**Tools:** Python · Scikit-learn · Pandas · Matplotlib · Seaborn
